# Ollama & Prompt Engineering Fundamentals

This project is created to learn and practice Large Language Models (LLMs),
Ollama, local open-weight models, Python integration, REST APIs, and prompt
engineering techniques.

## Technologies Used

- Ollama
- Llama 3.2
- Python
- Ollama Python Client
- Requests
- REST API
- Git & GitHub

## What is Ollama?

Ollama is a tool that allows us to run open-weight Large Language Models
locally on a computer.

It allows us to interact with models without sending our prompts to a
cloud-based AI service.
